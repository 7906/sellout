## 如何运行

需要两个终端（仓库根目录执行）：

```bash
# 终端 1：游戏服务器（127.0.0.1:3001）
npm run dev:server

# 终端 2：客户端（127.0.0.1:5173，/api 自动代理到 3001）
npm run dev:client
```

浏览器打开 <http://127.0.0.1:5173>，方向键/WASD 移动，点击 NPC 敲门，聊天套近乎，点「🤝 递合同」把货推出去——同一 NPC 买得越多你赚得越多。

**陌生拜访设定**：NPC 开门时不认识你——不知道名字、身份、来意，需要你自己开口介绍；没说的事 NPC 一概不知（可以试探猜测，但可能猜错）。买过你的东西之后 NPC 才会记住你是推销员。

其他命令：

```bash
npm run typecheck           # 三个 workspace 全量类型检查
npm run build -w client     # 客户端生产构建
npm run check:dayloop -w server  # 日循环/成交/存档往返冒烟测试（免 GLM）
```

## GLM 如何配置

1. 复制根目录 `.env.example` 为 `server/.env`
2. 到 <https://open.bigmodel.cn/> 申请 API Key
3. 填入 `GLM_API_KEY`，重启 `npm run dev:server`

```ini
GLM_API_KEY=你的智谱APIKey
GLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4   # Coding Plan 用 .../api/coding/paas/v4
GLM_MODEL=glm-4-flash                                # 当前使用 glm-5.3-flash（Coding Plan）
PORT=3001
```

- 未配置 Key 时服务器照常运行，NPC 返回「离线降级」安全回复（聊天面板 Debug 条会显示）。
- 配置后重启，Debug 条变为「GLM 在线」，NPC 由 GLM 驱动。
- Adapter 已适配 GLM-5.x 推理模型：`thinking: disabled`（NPC 对话无需推理，延迟 9s→2s）+ `max_tokens: 2000`（避免思考吃掉 JSON 输出预算）。
- 输出容错链：非法枚举映射安全值 → 非法效果过滤 → JSON 损坏时抢救台词字段 → 完全失败才用离线降级。任何降级都不产生状态效果。

## 销售循环（PHASE 9+11 最小版）

```text
开始页（继续游戏 / 新的开始·清档）
  ↓
敲门（点击 NPC）
  ↓
对话套需求：暖场聊天 → 信任↑、把人聊暖可泄怀疑↓（friendly/amused/excited 情绪有信任微结算+怀疑泄压）
  ↓
🤝 递合同（选背包里的商品）
  ↓
服务器闸门裁决：没买过 → 没踩 TA 的雷（隐藏成交条件，SALES_DESIGN）→ 信任≥门槛 → 怀疑<50 → 对这件货动过心思（兴趣门槛：≥¥1000 需兴趣≥40，≥¥250 需≥25）→ 买得起
  ├─ 通过 → 成交：NPC 存款扣款，玩家佣金+任务奖金入账
  └─ 拒绝 → 耐心↓ 怀疑↑（重复递已购商品不扣代价；明确拒绝后隔 3 回合自动消气）
  ↓
换下一件商品继续推——同一 NPC 买得越多，玩家赚得越多
  ↓
🌙 收工 → 日报（KPI 评分 + 街区新闻 + 明早邮件）→ 新的一天
```

**每日 KPI（真实任务，渐进难度）**：入账目标第 1 天 ¥50（一单中小生意可达标），之后每天 +¥25；HUD「📋 KPI」实时显示进度；收工按「入账/定额」评分（S≥200% / A≥100% / B≥60% / C>0 / D=白干），评语喜剧化。每日特殊任务难度也随天数解锁：前两天只刷 ★2，第 3-4 天 ★3，第 5 天起 ★4。新档开始自动弹玩法教程（六步含李老师攻略），HUD 的 ❓ 随时重看。

- 聊天中 NPC 主动说出「同意买」（intent=agree）也会自动触发同一闸门。
- 被拒原因会提示玩家：信任不够 / 怀疑太高 / 对货没动心思 / TA 买不起 / 已经买过 / 踩了 TA 的雷 / 条件没达成 / TA 正在气头上 / 刚成交先缓缓。
- **递合同有上下文台词**：成败由服务器裁决（权威），NPC 的反应台词由 LLM 按裁决结果 + 刚才的对话演绎（如「家里还有口锅能凑合用，您这我心里也没底」）——不再是与聊天脱节的罐头话。
- **实时攻略**：聊天框「📖 攻略」默认隐藏，点开显示当前成交诊断——每道闸（条件/信任/怀疑/商品匹配）过没过、差多少、怎么补，并推荐背包里最接近成交的商品；每轮对话后自动刷新。下面附静态攻略（每人的人设攻略与对症商品）。
- **成交条件**（SALES_DESIGN A）：每位 NPC 有隐藏的正反向条件（如逗笑钱大叔、别抢报价、给李老师看数据别吹牛、真诚道歉大刘），达成由 LLM 打标 + 服务器双重确认结算；反向条件当天判死、隔夜清除，正向跨天保留。
- **说了不该知道的事**：NPC 亲口说过的事（披露账本）你再提起，TA 不会起疑；没说过的私事你一开口，怀疑立刻上来。
- **多销有代价**：卖给同一 NPC 的第 2 件起，①成交冷却（须再聊满 2 回合才能递下一份）；②信任门槛 +5/件；③NPC 每件加怀疑 +8（怀疑几乎只涨不跌，唯一泄压方式是把人聊暖：NPC 表现 friendly/amused/excited 时服务器泄 8 点）——同一 NPC 实际能消化 3~4 件，想多赚就得广撒网或真聊透。
- NPC 买过的商品会注入其 prompt（不会买第二次，且可能拿出来念叨你）。
- 今日特殊任务（荒诞商品）只有一件库存：卖出 = 任务完成（佣金 + 25% 奖金），货从背包移除。

## 日循环（PHASE 17）

一天 = 一次营业：白天敲门店套近乎 → 点 HUD 的「🌙 收工」出日报 → 进入新的一天。

- **收工日报**：今日每单明细（卖给谁/什么货/佣金+奖金）、总入账、总资产、今晚街区新闻（喜剧层）、明早公司邮件（喜剧层 + 次日任务预告）。
- **跨天重置**：特殊任务重摇（昨天的没卖掉就当退回公司）、新任务货强制入背包、NPC 耐心回满/心情归零、会话线程清空（明天重新敲门）。
- **跨天保留**：天数、玩家资产、NPC 信任/怀疑/兴趣、购买记录——卖过你的人不会一夜失忆，反而会念叨你昨天卖的东西。
- 存档 v2 记录天数/今日任务/今日成交，收工瞬间落盘，重启不回退。

## 喜剧层（PHASE 18）

- **公司邮件**：每天一封（HUD「📧」按钮），KPI 从「卖出 3 件商品」逐日荒谬化——「卖给明确拒绝过你的人」「让街区接受一个以前不存在的消费习惯」，直至「把公司卖给公司」。逻辑成立，结论荒谬（GAME_DESIGN §11.1）。
- **街区新闻**：每晚日报里一条，NPC 和公司都一本正经地面对荒谬。

## 架构原则速记

- **Server Authority**：金钱、库存、NPC 心理数值只由服务器结算；LLM 只能从有限效果集合（`trust_up_small` 等 10 个）中选择，禁止任意数值。
- **管线**：玩家输入 → 上下文组装 → GLM → Zod 校验（失败重试 → 简化 Prompt → Safe Response）→ 效果结算 → 回复。
- **Debug**：每个回合 / 每次递合同都结构化落盘 `server/logs/conversations.jsonl`（会话ID、回合号、对话、情绪/意图、数值前后快照、效果、成交、LLM 原始输出、延迟、错误）。
- **复盘查看器**：游戏内点 HUD 的「📋 LOG」按钮，或直接打开 <http://127.0.0.1:5173/log-viewer.html>——按会话回放，可看每回合数值增减轨迹、每次递合同的裁决原因、LLM 原始输出。接口：`GET /api/debug/logs`。
- 聊天面板 Debug 条显示「信任/成交线」（如 信任 30/**35**），到位就能递合同。
